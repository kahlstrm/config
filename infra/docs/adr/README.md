# Architecture decision records

Each file records one decision: its context, the decision, and its
consequences, under a `Status` and `Date` line.

Name a new record `YYYY-MM-DD-<topic>.md`, using the date it is written, and
title it `# <Decision>` without a number. Refer to it by a link with a short
name, such as [the q35 ADR](0010-run-agent-vms-on-q35.md).

New records are not numbered, because a number taken from one branch can be taken
again on another before either merges. Records 1 to 11 keep their numbers and
their numbered references.
